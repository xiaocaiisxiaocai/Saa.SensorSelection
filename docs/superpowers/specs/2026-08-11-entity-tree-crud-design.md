# 实体树 CRUD 设计（客户 / 制程 / 机型）

日期：2026-08-11

## 目标

客户管理、制程管理、机型结构左侧树中的**分类（区域）**与**实体**支持增删改查；删除前必须先清空业务数据；实体可改所属分类。

## 方案

侧栏内联维护（方案 A）。

## 数据

- 持久化键：`entity-groups:customer|process|machine`，值为 `EntityGroup[]`
- 静态 `CUSTOMER_GROUPS` / `PROCESS_GROUPS` / `MACHINE_GROUPS` 仅作首次种子
- 存储仍为 `symtek_crud_store`

## 规则

- 实体改名：迁移 `listId:旧名` → `listId:新名`（含客户 `customer-sop`）
- 实体换分类：只改树归属
- 删除实体：相关业务列表与受控文档均为空才可删；否则返回 `not-empty`
- 删除分类：无下属实体才可删
- 新建实体：初始化空业务列表，避免套用种子默认样例

## 界面

- 侧栏：新建分类 / 新建实体；分类与实体行提供编辑、删除
- 编辑弹窗：名称；实体另含所属分类
