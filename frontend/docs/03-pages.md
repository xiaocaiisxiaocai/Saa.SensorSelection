# 03 · 信息架构与逐页规格

这份文档是**复刻清单**。表格列名、表单字段、校验、提示文案都是从现有代码逐条抄出来的，实施时当勾选表用。

## 1. 全局布局

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏 52px（材质 + 模糊）                                     │
│ [logo] 感应器选型     [全局搜索 ⌘K]        [主题] [用户菜单]     │
├────────────┬─────────────────────────────────────────────────┤
│ 导航侧栏    │ 页面内容区                                       │
│ 260px      │                                                 │
│ （材质）    │ 部分页面自带第二级源列表（可调宽 220–520）         │
└────────────┴─────────────────────────────────────────────────┘
```

- 工具栏：滚动时底部出现发丝线 + `--shadow-1`。
- 导航侧栏：macOS 源列表样式，分组标题 `--text-caption` `--label-2` 大写间距；选中项 `--sys-blue` 12% 底 + 蓝色文字 + 蓝色图标。可折叠为 56px 图标条。
- 后端状态横幅（`ABanner`）在工具栏下方，仅 `offline` / `unauthorized` 时出现。
- **移除 Vben 的多标签页（tabbar）**。Apple 桌面应用不用浏览器式标签页；导航靠侧栏。

### 导航结构

| 分组 | 项 | 图标 | 路由 | 权限 |
| --- | --- | --- | --- | --- |
| 感应器选型 | 客户管理 | `building-2` | `/selection/customer` | 匿名可读 |
| | 制程管理 | `factory` | `/selection/process` | 匿名可读 |
| | 机型结构 | `cpu` | `/selection/machine` | 匿名可读 |

| | 数据字典 | `book-type` | `/selection/dictionary` | 匿名可读 |
| 系统管理 | 用户管理 | `users` | `/system/user` | `rbac:view` |
| | 角色管理 | `shield-check` | `/system/role` | `rbac:view` |
| | 组织架构 | `network` | `/system/org` | `rbac:view` |
| | 操作日志 | `scroll-text` | `/system/audit-log` | `rbac:view` + `audit:view` |

隐藏路由：`/selection/search`（搜索结果，不进导航）、`/login`、404。

「系统管理」整组在无 `rbac:view` 时**不渲染**（不是禁用），沿用旧行为。

### 写权限门控

现有代码用 `v-can-write="'selection:write'"` 指令控制约 40 处按钮。新前端改为组合式：

```ts
const { canWrite } = useAccess()      // canWrite('selection:write')
```

规则（沿用旧语义）：**未登录可以只读预览全部业务数据**；无 `selection:write` 时所有新增 / 编辑 / 删除 / 上传 / 拖拽排序入口隐藏（不是禁用，与旧行为一致）。

## 2. 登录页 `/login`

- 居中卡片（宽 400px），背景用两层径向渐变（保留旧视觉，色值换成 `--sys-blue` / `--sys-teal` 的低透明度）。
- 品牌区：56×56 圆角方形 logo（`SAA`，渐变底）+ 标题「感应器选型软件」+ 副标题「Symtek Automation China · Sensor Selection」。
- 表单：用户名（`AField`，`maxlength=64`，`autocomplete="username"`）、密码（`AField type="password"`，`autocomplete="current-password"`，回车提交）。
- 主按钮「登 录」（`filled` `xlarge` `block`，带 loading）。
- 底部「以游客身份预览（只读）」文字按钮：点击**清除残留 token** 后跳转。
- 已持有有效 token 时打开本页 → 直接跳业务首页，不显示表单。
- 支持 `?redirect=` 回跳，默认落到 `/selection/customer`。
- 提示：未填 → `toast.warning('请输入用户名和密码')`；失败 → `toast.error(后端消息)`；成功 → `toast.success('登录成功')`。

## 3. 客户管理 `/selection/customer`

左侧 `ASourceList`（`groupLabel="区域"`、`itemLabel="客户"`）+ 右侧详情。URL 同步 `?category=&item=`。

切换客户时详情 tab 重置到第一个。无客户时右侧显示「暂无客户，请在左侧新建区域和客户」。

详情用 `ASegmentedControl`，4 个 tab：

### 3.1 客户通用要求（`customer-req`）

工具栏：计数文字（`匹配 N / 共 M 条` 或 `N 条客户要求`）、要求分类筛选与要求来源筛选（均为 `ATokenField` 多选，同一筛选内按任一匹配，首个标签后折叠为 `+N`）、搜索框（占位「搜索分类、机型、制程、内容、来源或备注」）、`新增要求`（主按钮）。

表格列：`要求分类` / `适用机型` / `适用制程` / `要求内容` / `来源` / `备注` / `操作`（编辑、删除图标按钮）。

弹窗「新增要求 / 编辑要求」（560px），两列网格：

| 字段 | 控件 | 必填 | 限制 |
| --- | --- | --- | --- |
| 要求分类 | `ASelect`（字典 `customer-req`） | 是 | |
| 来源 | `ASelect`（字典 `customer-req-source`） | 是 | |
| 适用机型 | `AField` | 否 | 100，占位「如 ALL」 |
| 适用制程 | `AField` | 否 | 100 |
| 要求内容 | `ATextArea` 3 行 | 是 | 600 |
| 备注 | `AField` | 否 | 200 |

提示文案：校验失败「请填写要求内容并选择有效分类与来源」；`storage` 失败「数据保存失败，本次修改未保存」；`stale`「该要求已被其他页面删除」；成功「要求已新增 / 要求已更新 / 要求已删除」。删除确认标题「删除要求」，正文 `确认删除"{内容}"吗？`。

空状态：有筛选「没有匹配的要求记录」，否则「暂无要求记录」。

### 3.2 制程注意事项（`customer-proc`）

工具栏：计数、制程分类筛选（`ATokenField` 多选，按任一匹配，首个标签后折叠为 `+N`）、搜索（「搜索分类、作用、特性、sensor注意或备注」）、`新增`。

表格列：`制程分类` / `制程作用` / `制程特性` / `sensor使用注意事项` / `备注` / `操作`。

弹窗字段：制程分类（`ASelect` 字典 `customer-proc`，必填）、制程作用（必填）、制程特性（必填）、sensor使用注意事项、备注。

### 3.3 感应器选用标准（受控文档）

按文件类型分区管理 PDF 与 Word 受控文档。

- 工具栏：搜索（「搜索文件名」）、上传入口（`AFileDrop`）。
- 上传限制来自 `CONTROLLED_FILE_RULES`：PDF 与 Word 各自的扩展名 / MIME / 大小上限，实施时从 `domain.js` 读取，不在 UI 里重复写死。
- 列表项：文件名、大小、上传时间、操作（预览 PDF、删除）。
- 预览用 `APdfViewer`（`ASheet` 承载），卸载调 `destroy()`。
- 校验失败提示：`size` → 文件大小超出限制；`type` → 文件类型不受支持。

### 3.4 厂外反馈问题项（`customer-feedback`）

工具栏：计数、问题分类筛选与处理状态筛选（均为 `ATokenField` 多选；同一筛选内按任一匹配，两个筛选之间同时满足；首个标签后折叠为 `+N`）、搜索（「搜索分类、机型、问题点、对策、时间或状态」）、`新增`。

表格列：`问题分类` / `适用机型` / `问题点` / `改善对策` / `反馈时间` / `处理状态`（`ABadge`）/ `操作`。

弹窗字段：问题分类（`ASelect` 字典 `customer-feedback`，必填）、适用机型、反馈时间（`ADatePicker`）、处理状态（`ASelect` 字典 `customer-feedback-status`，必填）、问题点（必填）、改善对策。

## 4. 制程管理 `/selection/process`

无侧栏，整页 `ASegmentedControl` 2 个 tab。URL 同步 `?tab=steps&q=`。

### 4.1 制程介绍

提供文件名搜索、拖放或点击上传、文件列表和删除操作；PDF 另可在线预览。支持 PDF、Word、PPT/PPTX，每个文件不超过 8 MB。

### 4.2 工艺制程

工具栏：计数、制程分层筛选（`ASelect`，字典 `process-layer`）、搜索（「搜索制程、工艺、作用、特性或备注」）、`新增`。

表格列：`制程` / `工艺制程` / `作用` / `制程特性` / `备注` / `操作`。分页 20/50/100。

弹窗（640px）：制程（`ASelect` 分层，必填）、工艺制程（`AField` 40，必填）、作用（`ATextArea` 2 行，500）、制程特性（`ATextArea` 2 行，500）、备注（`AField` 300）。

提示：`duplicate` → 「该工艺制程已存在」；`validation` → 「请填写工艺制程并选择制程分层」；成功「工艺制程已新增 / 已更新 / 已删除」；删除确认标题「删除工艺制程」。

切走 tab 时清空分层筛选（沿用旧行为）。

## 5. 机型结构 `/selection/machine`

最复杂的页面。左侧 `MachineSourceList` 使用「分类 → 配置 → 机型」三层树并启用复选；配置层可选，`专案机型` 等分类允许直接挂机型。分类、配置、机型编辑表单均提供 1 起算的排序字段，数组顺序即显示顺序。右侧为报告工具栏 + 动态 tab + 表格 + 示意图侧栏。

URL 同步 `?category=&configuration=&item=&section=`；无配置机型省略 `configuration`。

### 5.1 报告工具栏

- 左侧文字：`已选 N / M 个机型`。
- 按钮：`全选机型`（borderless）、`清空`（borderless，无选中时禁用）、`生成并下载报告`（filled，无选中时禁用，带 loading）、`预览 / 打印 PDF`（borderless，无选中时禁用）。
- 未勾选就点 → `toast.warning('请先在左侧勾选至少一个机型')`。
- 生成成功 → 下载 `机型结构示意图报告-YYYY-MM-DD.html`，`toast.success('后端报告已生成并下载，可打开后打印为 PDF')`。
- 预览走 `window.open`，按当前屏幕的工作区原点与可用宽高铺满打开，可缩放、可滚动并自动聚焦；多屏环境不得按主屏坐标错位。被拦截 → `toast.warning('报告窗口被浏览器拦截，请允许弹窗后重试')`。

### 5.2 用户自定义 tab（`ATabBar`）

tab 只来源于当前机型的 `machine-extra-sections:{机型名}`，不再加载历史全局 tab，也不从数据字典生成默认 tab；没有自定义 tab 时显示引导空态。排序按 `sort`。

- 每个 tab 悬停显示改名 / 删除图标按钮（需写权限）。
- 最右侧 `+ 新增 Tab` 按钮（需写权限）。
- Tab 弹窗（420px）：名称（`AField` 40，必填）、类型（`ASelect`：结构 / 机型注意事项）、排序（`AStepper`，最小 1）。有行或图片时不可切换类型。
- 提示：`duplicate`「该 Tab 名称已存在」；`not-empty`「请先清空该 Tab 下的全部数据后再删除」（切换类型时要求先清空数据和图片）；`stale`「该 Tab 已被删除，请刷新后重试」。

### 5.3 结构类 tab 的表格（`kind === 'structure'`）

工具栏：计数、传感器类型筛选（`ATokenField` 多选，字典 `sensor-type`，按任一匹配，首个标签后折叠为 `+N`）、搜索（「搜索功能作用、传感器类型、规格、作用或备注」）、`新增`。

表格列：

| 列 | 内容 |
| --- | --- |
| 功能作用 | `role` |
| 传感器类型 | 由 `sensorIds` 解析出的类型去重后以 `ABadge` 列出；无关联时回退显示旧 `sensorType` 字段或 `—` |
| 规格 | 由 `sensorIds` 解析：`{品牌} {型号} · {规格}`，多条换行；规格为空显示「未填写规格」；无关联时回退旧 `spec` 或 `—` |
| 作用 | `purpose` |
| 备注 | `note` |
| 操作 | 编辑 / 删除 |

**派生逻辑必须保留**：规格与型号实时来自 Sensor 型号字典，目录里替换型号后这里自动更新。

弹窗（520px）：功能作用（`AField` 80，必填）、关联传感器（`ATokenField` 多选，必填，选项按「现用 → 备选 → 停用」排序，标签含类型/品牌/型号/规格/非现用状态后缀，帮助文字「规格和型号来自 Sensor 型号字典；目录替换后这里会自动更新。」）、作用（`ATextArea` 3 行 500）、备注（`AField` 200）。

右侧「结构示意图」侧栏：
- 标题「结构示意图」+ 说明「一个结构最多 2 张」。
- 少于 2 张时显示「+ 添加」上传入口，`accept` 与 2MB 上限来自 `MACHINE_ROW_IMAGE_RULES`（`.jpg/.jpeg/.png/.webp`）。
- 缩略图卡片：点击开 `AImageViewer`（滚轮缩放 0.25–5、放大后拖拽平移、缩小/放大/重置按钮、百分比显示）；卡片底部显示文件名 + 删除按钮。
- 空态文字：「暂无示意图。上传后会在此结构下统一展示，不会重复到每个功能行。」
- 校验失败提示：`size`「图片大小不能超过 2 MB」；`type`「仅支持 JPG、PNG 或 WebP 图片」。

### 5.4 注意事项 tab 的表格（`kind === 'notes'`）

列：`注意分类` / `事项名称` / `说明` / `备注` / `操作`。搜索占位「搜索注意分类、事项名称、说明或备注」。无传感器类型筛选，无示意图侧栏。

弹窗：注意分类（80，必填）、事项名称（80，必填）、说明（`ATextArea` 3 行 500）、备注（200）。

## 6. Sensor 型号字典 `/selection/sensor`

顶部 `ASegmentedControl`：`SOP` + `资料` + `3D` + 各状态（现用 / 备选 / 停用，来自字典 `sensor-status`，按固定顺序排列）+ `全部`。`SOP` 是独立 PDF 文件库，不参与 Sensor 型号关联；`资料` 沿用历史 `sop` 内部标识，避免破坏旧数据和旧链接。

URL 同步 `?tab=sop-library`、`?tab=sop&sopId=`、`?tab=3d&model3dId=`、`?model=`、`?sensorTypes=漫反射,对照式`（从全局搜索跳进来时定位型号，自动切到「全部」并填入搜索词）。

### 6.1 目录表格

工具栏：计数、状态筛选（`ASelect`，含「全部」）、感应器类型筛选（`ATokenField` 多选，多个类型按任一匹配，首个标签后折叠为 `+N`）、搜索（「搜索类型、品牌、型号、料号、停用或问题点」）、`新增型号`。

表格列：

| 列 | 内容 |
| --- | --- |
| 状态 | `ABadge`：现用绿 / 备选（备用）黄 / 停用红 |
| 料号 | `partNumber`，空显示 `—`，等宽字体 |
| 感应器类型 | `sensorType` |
| 品牌 | `brand` |
| 型号 | `model`，等宽字体 |
| 关联资料 | 有则显示可点链接（外链图标 + 资料标题），点击切到资料 tab 并定位/预览；无则「未关联」 |
| 关联 3D | 有则显示可点链接（外链图标 + 3D 标题），点击切到 3D tab 并定位；无则「未关联」 |
| 问题点 | **仅「停用」tab 显示**，空显示 `—` |
| 替换关系 | 可点文字：`替换了 {品牌 型号} · {问题点}` 或 `被 {品牌 型号} 替换 · {问题点}`；点击跳到关联型号（切「全部」+ 填搜索词）；无则 `—` |
| 规格参数 | `spec`，溢出省略 |
| 特性与注意 | `feature`，溢出省略 |
| 适用场景 | `scene`，溢出省略 |
| 操作 | 编辑；`备选` 状态额外显示「替换现用」按钮；删除 |

分页 20/50/100。空状态「没有符合当前条件的型号」。

搜索匹配范围包含：状态、料号、类型、品牌、型号、规格、特性、场景、问题点、关联型号的型号/品牌/料号、资料标题、3D 标题。

### 6.2 弹窗「新增 / 编辑 Sensor 型号」（680px）

三列网格：状态（`ASelect`，必填）、料号（`AField` 80，占位「可选」）、感应器类型（`ASelect`，必填）。
两列：品牌（60）、型号（100，必填）。
单列：关联资料（`ASelect` 可清空，占位「可选，关联一份 PDF 资料」）、关联 3D（`ASelect` 可清空，占位「可选，关联一个 3D 文件」）、规格参数（`ATextArea` 2 行 500）、特性与注意（`ATextArea` 2 行 500）、适用场景（`AField` 300）。

提示：`duplicate`「该型号已存在，请使用不同的型号名称」；`validation`「请填写型号并选择感应器类型」；`stale`「该型号已被其他页面删除」。

### 6.3 弹窗「用备选替换现用型号」（560px）

- 顶部摘要：`备选：{类型 · 品牌 · 型号}`。
- 要替换的现用型号（`ASelect`，必填，候选 = 全部现用型号，**同类型排前面**并在标签后加「（同类型）」，占位「同类型优先，也可选其他现用」）。
- 问题点（`ATextArea` 3 行 500，必填，占位「说明因什么问题被替换」）。
- 未选目标 → `toast.error('请选择要替换的现用型号')`；未填问题点 → `toast.error('请填写问题点')`。
- 成功后切到「现用」tab，`toast.success('已替换现用型号，原型号已停用')`。
- `validation` 失败文案「仅备选可替换现用，且必须填写问题点」。

### 6.4 SOP tab

搜索（「搜索标题或文件名」）、上传、列表（标题、文件名、大小、上传时间、预览、删除）。SOP 仅支持 PDF（8 MB），预览用 `APdfViewer`，使用独立存储键 `sensor-sop-file:all`；当前不提供 Sensor 关联栏位。

### 6.5 资料 tab

搜索（「搜索标题或文件名」）、上传、列表（标题、文件名、大小、上传时间、预览、删除）。资料当前支持 PDF（8 MB），预览用 `APdfViewer`。为兼容历史数据，存储键仍为 `sensor-sop:all`、关联字段仍为 `sopId`；支持从目录页带 `sopId` 进入时高亮定位该条。

### 6.6 3D tab

搜索（「搜索 3D 标题或文件名」）、上传、列表（标题、文件名、大小、上传时间、下载、删除）。3D 文件暂仅支持 PDF，单文件不超过 8 MB。被 Sensor 型号关联的文件不可删除；从目录页带 `model3dId` 进入时高亮定位该条。

| `customer-feedback-status` | 厂外反馈状态 |
| `process-layer` | 制程分层 |
| `sensor-status` | Sensor 状态 |
| `sensor-type` | 感应器类型 |

左侧每项显示标题；建议同时显示 `description`（`--text-caption`），旧前端只在数据里有、没展示，加上更好用。

右侧表单：分类名称（`AField` 40，必填）、排序（`AStepper` 最小 1）。按钮：`新建`（重置表单）、`新增分类 / 更新分类`。

列表列：`排序` / `分类名称` / `操作`（编辑、删除）。

提示：`duplicate`「该分类名称已存在」；`validation`「请填写有效的分类名称」（删除时为「至少保留一个分类」）。删除确认：「确认删除“X”吗？已使用该分类的数据会改归到其他分类。」

## 8. 搜索结果 `/selection/search?q=`

- 顶部显示关键词与命中总数，`ASegmentedControl` 按类型过滤：全部 / 客户 / 制程 / 机型 / Sensor。
- 结果项：标题、类型 `ABadge`、分类、副标题（`sub`），点击按索引里的 `path` + `query` 跳转。
- 搜索索引由 `buildSearchIndex` 提供，覆盖客户、工艺制程、机型、机型结构行、Sensor 型号。
- 空结果：`AEmptyState`，提示换关键词。

## 9. 系统管理

### 9.1 用户管理 `/system/user`

表格列：`用户名` / `显示名` / `角色`（多个 `ABadge`）/ `所属组织`（显示完整路径）/ `状态`（`ABadge` 启用绿 / 停用灰）/ `创建时间` / `操作`（编辑、重置密码、删除）。

新建/编辑弹窗：用户名（必填，占位「登录账号」；编辑时不可改）、初始密码（**仅新建**，必填，占位「至少 6 位」）、显示名（必填，占位「姓名或称呼」）、角色（`ATokenField`，占位「可多选角色」）、所属组织（`ATreeSelect`，占位「可选择任意层级（支持跳级）」）、启用（`ASwitch`）。

重置密码弹窗：新密码（必填，占位「至少 6 位」）。

写操作需 `rbac:user:write`。

### 9.2 角色管理 `/system/role`

表格列：`标识` / `名称` / `描述` / `权限`（`ABadge` 列表）/ `类型`（系统内置 / 自定义）/ `操作`（编辑、删除）。

弹窗：角色标识（必填，占位「如：sensor_admin」；编辑时不可改）、角色名称（必填，占位「如：Sensor 管理员」）、描述（占位「角色用途说明（可选）」）、权限（按 `module` 分组的 `ACheckbox` 组）。

系统内置角色（`admin`）不可编辑 / 删除。写操作需 `rbac:role:write`。

### 9.3 组织架构 `/system/org`

树形展示（`childCount`、`userCount` 显示在名称后）。操作：新建子节点、编辑、删除。

弹窗：组织名称（必填，占位「如：电控事业部」）、层级（`ASelect` 可输入，占位「选择或输入层级（如：事业部/部门/课别）」）、同级排序（`AStepper`）。

写操作需 `rbac:org:write`。

### 9.4 操作日志 `/system/audit-log`

筛选栏：操作用户（`AField`）、操作类型（`ASelect`，占位「全部操作」）、结果（`ASelect`：全部 / 成功 / 失败）、时间范围（`ADatePicker range`，占位「开始时间」「结束时间」）。

表格列：`时间` / `用户` / `操作` / `目标` / `详情` / `结果`（`ABadge` + 文字）/ `说明` / `IP`。服务端分页。

需 `audit:view`。
