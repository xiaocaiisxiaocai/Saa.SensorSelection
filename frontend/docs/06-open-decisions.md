## 决策 1 · Windows 下的字体 — 已确认 A

**背景**：SF Pro（Apple 字体）和 SF Symbols（Apple 图标）的授权只覆盖 Apple 平台的应用，不能在 Web 上分发。你们的机器是 Windows，所以 macOS 上的效果不是实际效果。

选项：

| 方案 | 效果 | 代价 |
| --- | --- | --- |
| **A（已确认）** 自托管 Inter（拉丁）+ Noto Sans SC 子集（中文），Apple 设备上优先用系统 SF Pro / PingFang SC | Windows 与 macOS 观感接近；Inter 的骨架最接近 SF Pro | 字体文件约 300–600 KB（子集化后），首屏多一次字体加载 |
| B 纯系统字体栈，不自托管 | 零成本 | Windows 下落到微软雅黑，字形和间距与 Apple 差距明显，「苹果感」大打折扣 |
| C 只自托管拉丁部分（Inter），中文用系统 | 折中，约 100 KB | 中英混排时中文仍是雅黑，粗细不匹配 |

Phase 0 仍出 Windows 字体样张，用来验收子集覆盖（数字、拉丁、常用汉字），不是用来再选方案。

## 决策 3 · 无障碍底座 — 已确认 B

**背景**：`ASelect`、`AMenu`、`ASheet`、`ADatePicker`、`ATreeSelect` 这些组件的键盘导航和 ARIA 状态机很容易写漏。

选项：

| 方案 | 说明 |
| --- | --- |
| A 全部手写 | 零依赖，完全可控，但无障碍容易有隐性缺陷，且要多花约 1.5 个阶段 |
| **B（已确认）** 用 Radix Vue / Reka UI 做无样式底座，样式 100% 自己写 | 键盘与 ARIA 由成熟库保证，视觉仍完全是我们的 Apple 规范；多 1 个依赖 |

约束：底座只提供行为，不引入它的默认皮肤。组件视觉仍只准用 `tokens.css`。

## 决策 5 · 模块主题色 — 已确认 A

**背景**：旧前端给三个模块各配了一个主题色（客户 `#0f766e` 墨绿、制程 `#6d28d9` 紫、机型 `#b45309` 棕黄）。这三个色值在 Apple 调色板里都不存在，和 `--sys-blue` 同屏会显脏。

选项：

| 方案 | 说明 |
| --- | --- |
| **A（已确认）** 取消模块主题色，全局统一 `--sys-blue`，模块靠图标和标题区分 | 符合 Apple 单强调色的做法 |
| B 保留模块色概念，但换成 Apple 系统色（客户蓝、制程紫 `--sys-purple`、机型橙 `--sys-orange`） | 保留辨识度，仍在 Apple 调色板内 |

新前端禁止出现 `--module-accent` 或按路由换强调色。

## 决策 8 · 领域层 — 已确认「TypeScript 从零重写」

原推荐是原样拷贝 `domain.js` / `data.js` / `backend-storage.js`。你选择真正从零：UI 和领域层都用 TypeScript 重写。

| 方案 | 说明 |
| --- | --- |
| A 原样复用现有 JS（原推荐） | 风险最低，3900 行已有测试 |
| **B（已确认）** 用 TypeScript 从零重写 | 类型完整、目录干净；额外 2–3 个阶段；必须先写规格再写代码，否则会静默丢掉已修好的语义 |

硬约束（重写也不能改这些）：

- 业务规则与现有行为等价，不借机改需求。
- `localStorage` 主键仍是 `symtek_crud_store`，token 键仍是 `symtek_token`。
- 存储 key 模式、旧 key 迁移、写入失败回滚、离线快照、种子版本化回填必须保留。
- 对外入口仍是 `createSelectionRepository({ crudDefaults, sensorData, storage })` 这一形态，合同测试继续当护栏。
- **禁止**把现有 `domain.js` 复制进新目录再改名。对照旧实现写规格、按规格写新代码、用合同测试验收。

风险：写入回滚、`setItem(false)` 拒绝、机型行 `sensorIds` 多选派生、`machine-conveyor` 等旧 key 迁移、种子回填不覆盖用户数据——这些坑已经在旧代码里修过。重写等于再走一遍。对策是先写 [07-domain-spec.md](07-domain-spec.md)，再用现有 `domain.test.ts` + `vben-migration.contract-test.cjs` 当对照。
